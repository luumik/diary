# Verified engineering learnings

This file records durable, non-sensitive lessons that are likely to prevent a recurring, non-trivial Diary engineering problem. It is not a chronological activity log, error dump, scratchpad, or substitute for architecture and product documentation.

## Rules

- Add an entry only after the root cause and solution have been verified.
- Keep entries concise and broadly reusable.
- Link to stable project documentation or fictional regression tests when useful.
- Do not include diary data, user-entered values, secrets, environment values, tokens, local paths outside the repository, or raw command output.
- Do not record one-off syntax errors, speculative explanations, or issues already explained by primary documentation.
- Update or remove an entry when the underlying behavior changes.
