# Agent harness reference

This directory contains non-operative reference material. `AGENTS.reference.md` is preserved as a comprehensive example and is not an instruction file for this repository.

Agents must not load, follow, copy, or register capabilities from the reference unless the user explicitly requests work on it. In particular, its generic skill inventory does not grant permission to use external services, credentials, network access, GitHub mutations, releases, or deployments.

The active project instructions are in `../AGENTS.md`. Diary-specific procedures are in `../docs/agent-workflows.md`.
